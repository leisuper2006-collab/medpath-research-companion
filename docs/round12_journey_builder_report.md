# Round12 研究路径生成器建设报告

## 建设目标

用户强调科研新手不知道“方法是干什么的、从哪里开始、怎么把需求变成完整流程”。本轮新增 `Journey Builder` 页面，把一句自然语言需求拆解为数据准备、方法选择、开源工具、图谱、文章类型、审查规则和 Skill 调用链。

## 页面入口

- 路由：`/journey-builder`
- 首页按钮：`生成完整研究路线`
- 左侧导航：`研究路径生成器`
- 验证截图：`docs/round11_journey_builder_verified.png`

## 功能说明

页面接收用户输入的研究需求，例如“基因敲除后细胞状态变化分析”“Meta分析”“单细胞RNA测序”“病理PBL案例”。系统在本地数据中匹配：

1. 方法宇宙：从 674 个方法中推荐最相关方法；
2. 开源工具库：从 83 个工具中推荐实现入口；
3. 科研图谱：从 100 种图谱中推荐主图和补充图；
4. 文章工坊：从 28 类文章流程中推荐写作路径；
5. 数据审查室：从 72 条审查规则中提示字段、隐私和统计前提；
6. Skill 链：组合 research-copilot、medical-kg-rag-builder、skill-eval-harness、teacher-skill-maker 和 ai-ethics-governor 等能力。

## 面向新手的价值

这个页面不是再列一堆方法名，而是把“我想做什么”翻译为“先检查什么、用什么方法、看什么工具、画什么图、写什么文章、哪些地方要复核”。它可以作为科研小白进入几百个方法库之前的引导层。

## 真实性边界

路径生成器仅生成学习路线和项目设计草案，不代表真实研究结论。所有医学AI输出仅用于教学与科研训练，不替代临床诊断；真实研究执行仍需导师、伦理、数据授权和统计复核。
