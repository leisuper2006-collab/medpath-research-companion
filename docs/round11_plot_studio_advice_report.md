# Round 11 绘图室与数据审查联动报告

## 完成内容

本轮将科研绘图室从“选择图形并生成示例 SVG”升级为“先检查字段，再生成图”的新手友好流程。

新增接口：

- `POST /api/plot/advice`

接口输入：

- 图类型；
- 字段名或数据说明；
- 用户提供的字段列表。

接口输出：

- 该图回答的科研问题；
- 该图需要的字段；
- 用户已经提供的字段；
- 缺失字段；
- 数据审查命中规则；
- 下一步修复建议；
- 可复制到模型网关的规范化提示词；
- 医学 AI 安全边界。

## 页面更新

页面入口：

- `http://127.0.0.1:3000/plot-studio`

新增能力：

1. 用户选择图类型；
2. 粘贴字段名或数据说明；
3. 点击“先检查字段是否能画”；
4. 页面展示字段缺口、数据审查规则和修复建议；
5. 再生成 SVG 示例图；
6. 输出提示词可复制到模型网关，用于接入用户自己的模型 API。

## 边界

本功能不生成真实统计结论，不生成真实 p 值，不替代导师或统计专家判断。示例图仅用于教学和界面验证；真实科研绘图需要用户自有数据、source data、脚本版本、统计依据和教师/导师复核。
