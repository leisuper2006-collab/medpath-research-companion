# Round75 Research Island Game Progress

本轮目标不是继续做“说明卡片”，而是在 Round74 Three.js 小岛基础上继续靠近用户要求的科研游戏空间。

## 已完成

- 将科研小岛从 8 个建筑扩展为 16 个功能建筑。
- 新增建筑包括：模型塔、服务器码头、伦理花园、写作屋、统计站、单细胞温室、空间组学桥、积分商店。
- 每栋新增建筑都有独立用途、跳转页面、积分奖励和任务选项，不再用一套重复文案。
- 新增“我的科研建筑”面板，用户不需要精准点击 3D 模型，也可以从面板选择建筑。
- 建筑选择后会驱动同一套交互：角色移动、对话框切换、任务按钮出现、HUD 更新。
- 新增任务按钮：点击后加入待办并获得本地积分。
- 扩充建筑商店装饰条目，并保留“当前为本地原型反馈”的边界。
- 修复移动端小岛首屏：压缩上方说明，让游戏区更早出现。
- 修复移动端对话框和底部导航重叠问题，隐藏原生滚动条。

## 仍是 MVP 的部分

- 还没有真实账号系统；
- 还没有把建筑摆放写入后端；
- 还没有好友真实拜访、评论、私信；
- 排行榜仍是本地展示数据；
- 建筑兑换仍是本地反馈，尚未形成可拖拽库存；
- 医学 AI 相关输出仍限定为教学与科研训练，不替代临床诊断。

## 下一轮优先级

1. 做建筑拖拽/摆放模式，让用户能编辑小岛布局。
2. 把建筑和 Skill/方法/工具真实绑定，形成“我的常用科研功能”。
3. 给小岛增加角色移动目的地标记、对话气泡和更像游戏的按钮音效/动画。
4. 补个人主页与小岛之间的数据联动：我的 Skill、我的案例、我的绘图作品可以放进建筑。
5. 继续改善移动端，目标是打开小岛后第一屏就像一个可玩的游戏入口。
