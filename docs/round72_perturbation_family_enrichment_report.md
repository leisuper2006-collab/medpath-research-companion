# Round72 Perturbation Family Enrichment Report

本轮优先修复高相似度最集中的实验扰动家族，使基因敲除、基因敲低、CRISPR筛选、过表达和药物扰动拥有差异化产品详情页叙事。

## Updated methods
- `method-001` 基因敲除入门流程: 单基因完全敲除是否适合你的问题
- `method-002` 基因敲除进阶设计: 从一个候选基因走向可复核的敲除设计
- `method-003` 基因敲除质量控制: 敲除实验的质量控制不是最后补一句
- `method-004` 基因敲除结果解读: 敲除结果要解释为证据链，不是单句因果
- `method-005` 基因敲除常见误区: 敲除实验最常见的五个陷阱
- `method-006` 基因敲低入门流程: 敲低适合回答“降低表达会怎样”
- `method-007` 基因敲低进阶设计: 敲低进阶设计要控制剂量和时间
- `method-008` 基因敲低质量控制: 敲低QC关注残余表达和非特异效应
- `method-009` 基因敲低结果解读: 敲低结果更适合写成表达依赖性证据
- `method-010` 基因敲低常见误区: 敲低误区集中在短期、剂量和脱靶
- `method-011` CRISPR筛选入门流程: CRISPR筛选用于从很多基因里找候选
- `method-012` CRISPR筛选进阶设计: 筛选设计核心是覆盖度和选择压力
- `method-013` CRISPR筛选质量控制: 筛选QC先看文库是否还活着
- `method-014` CRISPR筛选结果解读: 筛选结果解读要从命中到验证
- `method-015` CRISPR筛选常见误区: 筛选误区是把发现当验证
- `method-016` 过表达入门流程: 过表达用于测试“增加它是否足够”
- `method-017` 过表达进阶设计: 过表达进阶设计要处理剂量和定位
- `method-018` 过表达质量控制: 过表达QC重点是表达是否可信
- `method-019` 过表达结果解读: 过表达结果需要和内源表达对照
- `method-020` 过表达常见误区: 过表达误区是强信号掩盖弱证据
- `method-021` 药物扰动入门流程: 药物扰动先回答剂量是否合理
- `method-022` 药物扰动进阶设计: 药物扰动进阶设计要加入替代药物和遗传验证
- `method-023` 药物扰动质量控制: 药物扰动QC要看活性、毒性和批次
- `method-024` 药物扰动结果解读: 药物扰动结果解读要区分作用和机制
