# Round 11 游戏化学习空间与桌宠设计

## 1. 产品定位

游戏化空间不是把科研严肃任务“玩具化”，而是给科研新手一个低门槛入口。用户在小岛中移动、点击建筑、与桌宠对话，最终仍进入标准化方法页、文章Skill、绘图工作室和数据审查流程。

名称建议：

- 英文：MedPath Research Island
- 中文：科研小岛

## 2. 美术方向

核心风格：

- 动物之森式低多边形岛屿；
- 梵高星空式背景纹理；
- 医学切片、细胞、星云、知识路径作为视觉隐喻；
- 温暖、圆润、低压力；
- 不使用医院logo、学校logo或真实患者图像；
- 证据型图表仍保持白底、清晰、严肃。

## 3. 场景建筑

| 建筑 | 功能入口 | 新手解释 |
|---|---|---|
| 方法图书馆 | 方法宇宙 | 不知道方法名时，先按研究问题找方法 |
| 基因工坊 | 基因敲除/扰动家族 | 了解CRISPR、RNAi、Perturb-seq等区别 |
| 绘图画室 | 科研绘图工作室 | 先选科研问题，再选图 |
| 文章工坊 | 20+文章Skill | 从0搭建Meta分析、综述、机制文章流程 |
| 数据诊所 | 数据审查 | 检查列名、缺失、分组和图表适配 |
| 模型驿站 | 用户API配置 | 接入自己的大模型API，不保存密钥 |
| 审计塔 | 伦理治理 | 检查隐私、临床误导、伪造引用 |
| 成果邮局 | 导出与发布 | 导出Word、Markdown、图表、投稿清单 |

## 4. 桌宠设计

候选名称：

- 小派；
- Pathy；
- 小切片；
- 星星细胞。

桌宠功能：

1. 解释当前页面；
2. 帮用户选择下一步；
3. 提醒安全边界；
4. 根据用户输入推荐方法、文章Skill或图表；
5. 显示“我能帮你做什么”菜单；
6. 切换严肃模式/新手模式/游戏模式。

桌宠对话示例：

> 你想做“基因敲除”吗？我先帮你分清：你是想永久敲除、暂时敲低、激活基因、还是做高通量筛选？选错方法会影响整个实验设计。

## 5. 首版交互

首版不追求大型游戏系统，先做可用的网页游戏原型：

1. Three.js画一个低多边形科研岛；
2. 岛上8个可点击建筑；
3. 点击建筑打开对应功能弹窗；
4. 桌宠固定在右下角；
5. 点击桌宠弹出任务向导；
6. 点击地面后角色移动到目标点；
7. 完成任务后给徽章提示。

## 6. 后续技术路线

首选技术：

- Three.js 或 React Three Fiber；
- HTML对话框叠加；
- 本地JSON任务配置；
- 后续可加入GLTF模型。

风险：

- 3D资产制作会消耗时间；
- 游戏空间不能替代严肃工作台；
- 移动端性能需要单独优化；
- 必须避免花哨到影响科研任务。

## 7. 第一个可实现版本

建议下一轮实现：

- `/island` 游戏模式页面；
- 一个低多边形岛屿背景；
- 8个建筑按钮；
- 一个桌宠组件；
- 点击建筑跳转到现有页面；
- 桌宠给出任务建议；
- 不做复杂角色动画，先做可点击导航。
