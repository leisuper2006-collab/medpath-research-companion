# Round 10 前端重构与科研新手友好化报告

## 一、用户反馈对应问题

本轮用户指出旧版页面存在三类核心问题：第一，视觉风格像临时目录页，缺少正式科研教育平台的层次；第二，方法说明太薄，科研新手不知道每个方法解决什么问题、需要什么输入、会产生什么输出；第三，功能虽有接口，但页面没有把“解决什么、怎么用、谁来复核、风险在哪里”讲清楚。

## 二、参考平台与转化方式

本轮参考了若干成熟科研/AI平台的信息组织方式，但未复制外部代码或文案。

| 参考对象 | 借鉴点 | 本项目转化 |
|---|---|---|
| Hugging Face Tasks / Spaces | 以任务为入口，说明输入输出与可试用demo | 首页新增“按任务开始”，先选课程、案例、报告、方法、绘图、审计 |
| Galaxy Project / Workflow | 用流程方式解释输入、工具步骤、中间结果和输出 | 方法理解器新增“输入 → 预处理 → 模型 → 预测 → 解释与验证” |
| WorkflowHub | 强调可复用工作流、版本、license、测试和来源 | 开源工具库增加license待核对、学习路径、误区、工具用途 |
| OpenAI GPTs / 插件卡 | 卡片先讲用途、starter prompts、能力和权限 | 插件中心改成能力卡，展示解决问题、输入、输出、安全边界 |
| CELLxGENE Discover | 给新手“从示例开始”的入口 | 科研新手导航按问题推荐方法与下一步操作 |
| Streamlit Gallery | 成品展示与源码/复用入口结合 | 科研绘图室从“图能回答什么问题”出发，再生成SVG示例 |

## 三、已完成改造

1. 重构 `apps/web/static/app.js`，将站点从目录式页面改为任务式工作台。
2. 重构 `apps/web/static/styles.css`，使用左侧导航、顶部命令栏、任务卡、插件能力卡、方法流程卡和更清晰的分栏布局。
3. 新增 `/api/method-guides`，读取 `data/method_learning_guides.json`。
4. 首页新增“按任务开始”：设计病理课、生成PBL案例、批改报告、找科研方法、科研绘图、AI输出审计。
5. 科研新手导航新增“按问题选方法”表格和学习指南卡片。
6. 插件中心卡片新增：能解决的问题、需要的输入、产生的输出、安全边界、starter prompts。
7. Skill详情页新增：新手解释、什么时候用、输入要求、输出怎么看、常见误区、学习路径。
8. 方法理解器新增虚拟扰动流程图和相关工具标签，避免重复卡片刷屏。
9. 开源工具库新增用途、输入输出、常见误区和license待核对提示。
10. 保留并增强医学AI安全边界：本地原型、mock模型、不处理真实患者数据、不替代临床诊断。

## 四、验证结果

已运行：

- `pytest apps/api/tests -q`
- `python scripts/validate_interactions.py`
- `python scripts/capture_screenshots.py`

交互验证覆盖教师PBL、学生反馈、模拟案例、对照实验、开源搜索、科研绘图、Skill Builder、Provider mock连接和治理审计。

## 五、仍建议继续增强

1. 如果 Node.js 环境恢复，可迁移到 Next.js/React 组件化实现，进一步提升交互细腻度。
2. 方法卡可继续按真实研究方向补充更多可运行demo，例如单细胞QC、空间组学、RAG文档构建、病理图像预处理。
3. 可增加“新手问答式向导”，让用户回答3-5个问题后自动推荐方法、Skill和工具。
4. 后续若接入真实平台，需增加登录、权限、审计日志、D03字段映射和D10评价回传，但不能在本地原型中伪造成已上线。
