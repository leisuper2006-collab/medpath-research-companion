# Round 11 Figma手机端App设计简报

## 1. 手机端定位

手机端不应照搬桌面端复杂工作台，而应成为“科研任务伴侣”。用户在手机上快速查方法、看学习路径、记录文章流程、查看图表建议、接收复核提醒；复杂数据处理仍回到电脑端完成。

建议名称：

**MedPath Companion**

中文名：

**MedPath科研伴侣**

## 2. 用户画像

1. 科研小白：不知道方法名，需要按问题选择方法；
2. 研究生：需要管理论文流程、图表、数据检查和导师反馈；
3. 教师：快速查看学生任务、复核AI输出；
4. 课程团队：查看Skill运行记录和教学案例状态。

## 3. 底部导航

1. 今日任务；
2. 方法；
3. 文章；
4. 绘图；
5. 我的。

## 4. 核心页面

### 4.1 今日任务

- 桌宠问候；
- 今日待办；
- 继续上次任务；
- 安全提醒；
- 快速入口：找方法、写文章、画图、审计输出。

### 4.2 方法页

- 搜索框；
- 按用途分类；
- 基因敲除/扰动家族入口；
- 方法卡片：解决什么、输入、输出、误区；
- 收藏和学习进度。

### 4.3 方法详情页

- 一句话解释；
- 什么时候用；
- 不适合什么；
- 输入材料；
- 输出结果；
- 示例图；
- 推荐文章；
- 常见误区；
- 下一步学习。

### 4.4 文章工坊页

- 文章类型列表；
- Meta分析、综述、单细胞、机制研究等；
- 每个类型显示进度条；
- “从0开始搭流程”按钮。

### 4.5 Meta分析流程页

- PICO；
- 检索式；
- 文献筛选；
- 数据提取；
- 风险偏倚；
- 森林图；
- 写作结构；
- 投稿检查。

### 4.6 绘图助手页

- “我想回答什么问题”；
- 推荐图类型；
- 示例图；
- 数据格式要求；
- 上传到电脑端继续处理。

### 4.7 桌宠对话页

- 聊天式任务选择；
- 不替代临床诊断提示；
- 推荐方法/文章/图表；
- 导航到对应页面。

### 4.8 我的页面

- 收藏方法；
- 文章进度；
- 运行记录；
- 复核记录；
- API配置状态；
- 安全与隐私。

## 5. 视觉风格

- 背景：柔和星空/切片纹理，不影响阅读；
- 色彩：深蓝文字、医学绿、星空蓝、暖黄色点缀；
- 卡片：少而清晰，不堆叠；
- 插画：桌宠、方法图标、科研岛元素；
- 字体：中文可读优先；
- 移动端按钮足够大，避免密集表格。

## 6. Figma交付建议

需要制作以下Frame：

1. App启动页；
2. 今日任务首页；
3. 方法分类页；
4. 基因敲除方法家族页；
5. 方法详情页；
6. 文章工坊页；
7. Meta分析流程页；
8. 绘图助手页；
9. 桌宠对话页；
10. 我的/设置页。

## 7. Android实现路线

短期：

- PWA + 手机响应式网页；
- Android WebView壳；
- 用Android emulator做基础QA。

中期：

- Expo/React Native；
- 复用方法库、文章Skill和API；
- 增加本地通知、收藏、离线阅读。

长期：

- 原生Android；
- 深度权限、文件选择、离线缓存和校园账号接入。

## 8. 需要确认

若要直接在Figma中创建文件，需要确认：

- Figma使用哪个团队/组织；
- 是否允许使用生成图资产；
- 是否需要学校/团队品牌色；
- 手机端优先做iOS风、Android Material风，还是自定义MedPath风。
