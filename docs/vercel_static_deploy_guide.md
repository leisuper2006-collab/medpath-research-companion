# Vercel 静态部署指南

本项目提供 `vercel.json`，可将 `dist/github-pages-demo` 作为静态演示站发布。该路线适合快速生成可访问链接，供申报、答辩、课程团队预览。

## 1. 部署逻辑

Vercel 执行：

```bash
python scripts/build_static_release.py
```

构建产物：

```text
dist/github-pages-demo/
```

所有路由 rewrite 到 `index.html`，由前端静态路由处理。

## 2. 环境变量

静态演示版不需要配置真实 API Key。请不要在 Vercel 环境变量中填入临床、HPC 或学校平台敏感凭据，除非后续明确切换为服务端部署并完成安全审计。

## 3. 适合展示的内容

- 方法详情页的 Apple 式滚动说明；
- 每个方法/图谱/文章/工具的专属介绍；
- 示例图和公开来源线索；
- 研究路径生成器；
- 模型网关 mock 请求包；
- 3D 科研小岛。

## 4. 不适合在静态版展示的内容

- 真实模型调用结果；
- 真实课程评价数据；
- 真实患者材料；
- 私有课程课件；
- 未授权论文图；
- HPC 真实提交记录。

## 5. 部署后验收

部署完成后，打开首页并依次点击：

1. 方法宇宙；
2. 文章工坊；
3. 图谱宇宙；
4. 开源工具库；
5. 研究路径生成器；
6. 3D科研小岛。

若页面空白、中文乱码、示例图缺失或安全边界消失，应回滚部署并重新运行本地审计。
