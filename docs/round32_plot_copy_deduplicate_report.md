# Round32 图谱文案去模板化报告

- 修订图形数量：100
- 修订字段：`plot_when_to_use`、`plot_hero_subtitle`、`plot_data_contract[].meaning`。
- 原则：每张图围绕不同读图动作、字段核对和误区边界写说明；不改变示例图，不伪造真实数据。

## 样例

### 火山图 (volcano_plot)
课题组第一次组会最适合拿出火山图：它要让新手先盯住点的位置、颜色和阈值线，再判断“同时扫视效应方向、效应大小和校正显著性”。如果你的研究问题是“识别组间、条件间或基因组位置上的差异信号。”，请先把feature_id、group、estimate、p_value整理成可追溯字段表，并在图注里写清来源、分组和阈值。不要把右上角/左上角的点直接说成机制靶点，先回到差异分析表和多重检验。不能跳过原始字段和清洗脚本；正式使用前还要保存代码、source data和人工复核记录。

### MA图 (ma_plot)
