# Round27 产品式详情页与视觉升级记录

## 目标

本轮针对“每个最小单元都要像苹果官网产品页一样点进去有独立解释、真实来源、示例图、学习路径和需求窗口”的要求，完成了四类升级：

1. 方法卡、绘图卡、文章流程卡、开源工具卡均补充差异化详情叙事。
2. 方法详情页强化“方法总览—来源边界—学习路径—需求窗口—导师复核—字段契约”的长页结构。
3. 右下角桌宠升级为按页面上下文变化的科研导师，不同页面给出不同入口、材料、避坑提示和任务包。
4. 增加高端视觉参考图，作为后续Figma或正式视觉重构的设计基准。

## 已落地到页面的结构

方法详情页已包含：

- 顶部方法总览：说明该方法回答什么问题、适合什么材料。
- 示例图区域：显示由本项目生成的教学示例SVG，用于学习读图方式。
- 来源边界区域：标注公开数据或教程入口、引用边界和复用边界。
- 学习路径区域：将方法拆成判断、准备、执行、出图、复核等动作。
- 小白执行区：准备什么、怎么做、得到什么、看什么图、常见错误。
- 字段契约区：列出输入数据字段、必需/可选状态和说明。
- 需求窗口：用户可填写真实任务，生成新手任务包。
