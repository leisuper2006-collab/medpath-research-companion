# violin

This folder contains a reproducible teaching example for the plot type.

- `example.png`, `example.svg`, `example.pdf`: exported figures
- `example_data.csv`: source data used by the demo
- `plot.R`, `plot.py`: starter scripts
- `caption.md`, `methods.md`, `api_prompt.md`: writing and BYOK guidance

Boundary: this is a synthetic or public-style teaching example. It is not clinical evidence and must not be used for patient diagnosis.
