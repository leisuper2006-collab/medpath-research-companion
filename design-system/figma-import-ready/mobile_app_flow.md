# MedPath 移动端 App 路线

## 定位

MedPath 移动端不是桌面平台的压缩版，而是给科研新手随时查方法、看图形、搭流程、保存复核清单的轻量入口。

## 核心用户路径

### 路径一：一句话找研究路线

1. 用户输入：“我想做胃癌单细胞免疫微环境分析”。
2. App 返回：推荐方法、数据要求、图谱、文章类型、Skill链。
3. 用户选择一个方法。
4. 进入方法详情，查看示例图和字段契约。
5. 生成导师复核清单。

### 路径二：我有数据但不知道画什么图

1. 用户粘贴字段名。
2. App 进行数据审查。
3. 返回适合图谱和不能画的图。
4. 用户点进图谱详情。
5. 查看示例图、R/ggplot2提示和模型网关提示词。

### 路径三：我要写一篇文章

1. 用户选择文章类型，例如 Meta 分析。
2. App 显示从0到1流程。
3. 用户补研究问题和材料状态。
4. App 生成文章任务包。
5. 用户导出给导师复核。

### 路径四：游戏化学习

1. 用户进入科研小岛。
2. 点击建筑；
3. 小人移动并弹出解释；
4. 用户进入正式功能页；
5. 完成任务后点亮建筑。

## 手机端页面

1. `Home`：今日任务、快速输入、安全边界。
2. `Journey`：一句话研究路径生成器。
3. `Methods`：方法分类、基因敲除家族、常用方法。
4. `Plots`：图谱搜索、示例图、字段审查。
5. `Articles`：文章类型、从0到1流程。
6. `Island`：游戏化学习地图。
7. `Review`：导师复核清单、伦理审计、导出记录。

## 视觉建议

- 白底科研产品风，不做廉价AI渐变。
- 用植物、岛屿、实验台、文献页作为轻量视觉隐喻。
- 控件紧凑，文字分层清晰。
- 每个小卡片必须写不同内容，不能复制同一段模板。

## 真实性边界

移动端只提供教学与科研训练辅助，不替代临床诊断，不处理真实患者隐私，不生成真实研究结论。
